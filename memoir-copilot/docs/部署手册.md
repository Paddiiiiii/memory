# 部署手册（V1）

## 依赖

- Docker / Docker Compose
- 腾讯云：CVM、TencentDB PostgreSQL、Redis、COS
- 域名与 TLS（Staging/Prod）

## 本地开发

1. 启动 Postgres + Redis：`infrastructure/docker/docker-compose.yml` 可只起 postgres/redis
2. `cd backend && cp .env.example .env && uv sync`
3. `uv run alembic upgrade head`
4. `uv run python -m scripts.bootstrap_admin`
5. `uv run uvicorn app.main:app --reload --port 8000`
6. `uv run celery -A app.workers.celery_app.celery_app worker -l info`
7. `cd desktop && pnpm install && pnpm dev`

## 密钥

- 禁止提交 Secret
- 生产注入：Secret Manager / 部署环境变量
- 首次 bootstrap 后移除 `BOOTSTRAP_ADMIN_PASSWORD`

## 备份

- PostgreSQL 日备
- COS 版本控制 + Lifecycle
- Soft delete 7 天；备份残留最长 30 天
