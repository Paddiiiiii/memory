# 部署手册（V1）

## 依赖

- Docker / Docker Compose
- （生产）腾讯云：CVM、TencentDB PostgreSQL、Redis、COS
- 域名与 TLS（Staging/Prod）

## 本地一键（推荐）

```bash
cd backend && cp .env.example .env
# 编辑 .env：OPENAI_API_KEY、TENCENT_ASR_*（按需）

cd ../infrastructure/docker
docker compose up -d --build
curl http://127.0.0.1:8000/health
```

桌面端（录音）：

```bash
cd desktop
cp .env.example .env   # 可选
pnpm install && pnpm tauri:dev
```

## 本机分项启动

1. 启动 Postgres + Redis：`docker compose up -d postgres redis`（在 `infrastructure/docker`）
2. `cd backend && cp .env.example .env && uv sync`
3. `uv run alembic upgrade head`
4. `uv run python -m scripts.bootstrap_admin`
5. `uv run python -m scripts.seed_prompts`
6. `uv run uvicorn app.main:app --reload --port 8000`
7. `uv run celery -A app.workers.celery_app.celery_app worker -l info`
8. `cd desktop && pnpm install && pnpm tauri:dev`

## 密钥

| 变量 | 用途 |
|------|------|
| `TENCENT_ASR_APP_ID` / `SECRET_ID` / `SECRET_KEY` | 实时字幕 WSS 签票 |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` | 现场分析 LLM |
| `COS_*` | 可选对象存储；空则本地 `.data/media` |
| `SECRET_KEY` | JWT；上线必改 |
| `BOOTSTRAP_ADMIN_*` | 首次管理员；上线后移除密码注入 |

- 禁止提交 `.env`
- 生产注入：Secret Manager / 部署环境变量

## 备份

- PostgreSQL 日备
- COS 版本控制 + Lifecycle（若启用）
- Soft delete 7 天；备份残留最长 30 天
