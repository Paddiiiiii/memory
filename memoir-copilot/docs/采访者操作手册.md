# 采访者操作手册（草案）

1. 登录（管理员开户的邮箱密码）
2. 新建项目 → 填写受访者称呼 → 勾选 Consent A（录音）；按需勾选 Consent B（云端 AI）
3. 建议受访者口头确认录音与 AI 整理
4. 建议先开 Apple Watch Voice Memos，再点「开始采访」（会播放同步音）
5. 采访中关注右侧「当前建议」；可用「换个方向」「没说完的故事」「人生第一次」「准备收尾」
6. 结束采访需二次确认；等待本地 finishing 完成后再离开
7. 访谈后导入 Watch 录音（可选），等待双音源校准与 Final Replay

快捷键：

- ⌘⇧R 开始/结束
- ⌘⇧P 暂停/继续
- ⌘M 标记
- ⌘N 笔记
- ⌘F 搜索（后续）
